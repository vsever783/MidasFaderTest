# Midas Fader Control

Android-приложение (Kotlin) для управления пультом **Midas Pro2** по сети —
собственная реализация протокола Pro2/PPC поверх UDP, полученная реверс-инжинирингом
(сравнение трафика официального Mixtender 2 через Wireshark + сверка со
сторонним списком команд [muffeeee/midas-pro-series-osc-commands](https://github.com/muffeeee/midas-pro-series-osc-commands)).

В одном APK — два режима:

- **Midas Fader Control** — полный интерфейс для звукорежиссёра: все 56
  входных каналов, мастер, aux returns, aux-шины.
- **Midas Monitor** — упрощённый интерфейс для музыканта: выбор своей
  мониторной aux-шины и управление посылами каналов в неё.

> ⚠️ **Пульт — это не игрушка.** Команды `--set` двигают реальные фейдеры на
> реальном пульте немедленно. Тестируйте только на холостом пульте (не во
> время живого шоу), особенно всё, что помечено ниже как "не подтверждено".

## Возможности

### Звукорежиссёрский режим

| Функция | Статус |
|---|---|
| Фейдер, Mute, Solo, Gain | ✅ подтверждено реальным трафиком |
| Имя и цвет канала (живые, с пульта) | ✅ подтверждено |
| Живые метры (VU) | ✅ подтверждено |
| Компрессор (ratio/attack/release/threshold/makeup/in) | ✅ подтверждено |
| Эквалайзер (4 полосы: freq/gain/width + вкл/выкл) | ⚠️ подтверждено только описанием в списке команд |
| Посылы канала на 16 aux-шин | ⚠️ не подтверждено реальным захватом |
| Мастер, Aux Returns (8), сами aux-шины (16) | ⚠️ не подтверждено реальным захватом |
| Банки каналов (по 8), альбомная/портретная ориентация | ✅ |

### Мониторный режим

- Список всех 16 aux-шин (с живыми именами) при подключении
- Посылы всех каналов в выбранную свою шину — слева
- Громкость и mute самой шины — справа
- Каналы постранично, по 8 за раз
- Работает в портретной и альбомной ориентации

## Технические особенности протокола (важно при доработке)

- Пульт **не отвечает** на прямой `--get` по человекочитаемому пути. Живые
  обновления идут только через подписку `/batchsubscribe` с клиентским
  хендлом + периодический `/renew` (~3 сек) для продления — без него пульт
  отключает подписку через какое-то время.
- Хендлы подписки должны быть **уникальными на сессию** (иначе пульт может
  путать данные со старыми подписками прошлых запусков).
- Push-значения (через подписку) кодируются в **little-endian**, а команды
  `--set`/`--get` — в **big-endian** (стандартный OSC). Это разные части
  протокола с разным порядком байт — частый источник багов при добавлении
  новых команд.
- Цвет канала — не обычный ARGB: байты идут в порядке **R, G, B, A**.
- Реализована защита от разрыва соединения при повороте экрана
  (`ConnectionHolder` — синглтон вне жизненного цикла `Activity`).

Подробный уровень уверенности по каждой конкретной команде — прямо в
комментариях `Pro2Commands.kt`.

## Сборка

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите на устройстве в одной сети с пультом (`Run` → выбрать
   устройство).

Требования: Android Studio, minSdk 24, compileSdk 34, Kotlin.

## Пульт

Тестировалось на **Midas Pro2** (56 входных каналов, 8 aux returns, 16
aux-шин, 3 мастер-канала, 8 VCA-групп, до 6 mute-групп). Другие консоли
Pro-серии (Pro1/Pro3/Pro X) могут частично поддерживаться, но не проверялись.

## В планах

- Gate (переключатели есть, continuous-параметры threshold/attack/release/range
  ещё не найдены в списке команд — нужен целевой захват трафика)
- VCA-группы (особая адресация — номер группы зашит в имя параметра)
- Mute-группы
- Переименование/перекраска каналов из самого приложения (команды уже есть)
- 48V, переворот фазы, отдельная ручка gain trim
