# Midas Fader Control

Android-приложение (Kotlin) для управления пультом **Midas Pro2** по сети —
собственная реализация протокола Pro2/PPC поверх UDP, полученная реверс-
инжинирингом (сравнение трафика официального Mixtender 2 через Wireshark +
сверка со сторонним списком команд
[muffeeee/midas-pro-series-osc-commands](https://github.com/muffeeee/midas-pro-series-osc-commands)).

Одно приложение, один значок. При запуске — экран выбора роли:

- **ЗВУКОРЕЖИССЁР** — полный интерфейс: все 56 входных каналов, мастер, aux
  returns, 16 aux-шин, 8 VCA-групп.
- **МУЗЫКАНТ (МОНИТОР)** — упрощённый интерфейс: выбор своей мониторной
  aux-шины, посылы всех каналов в неё, громкость и mute самой шины.

Оба режима используют **одно и то же** сетевое подключение (порт 10001).
Так было не всегда — раньше это были два отдельных значка/приложения с
разными портами, и при одновременной работе с одного телефона пульт путал,
куда слать ответы (он различает клиентов по IP, а не по порту). Объединение
в один режим внутри одного приложения решило эту проблему полностью.

> ⚠️ **Пульт — это не игрушка.** Команды `--set` двигают реальные фейдеры на
> реальном пульте немедленно. Тестируйте на холостом пульте, особенно всё,
> что помечено ниже как "не подтверждено".

## Возможности

### Звукорежиссёрский режим

| Функция | Статус |
|---|---|
| Фейдер, Mute, Solo, Gain, Pan | ✅ Pan и Gain подтверждены реальным захватом |
| 48V, переворот фазы | ✅ 48V подтверждено захватом; фаза — по описанию в списке команд |
| Имя и цвет канала (живые, с пульта) | ✅ подтверждено |
| Переименование/перекраска канала из приложения | ✅ |
| Живые метры (VU) | ✅ подтверждено |
| Компрессор + фильтр (сетка ручек + график передачи) | ✅ подтверждено реальным захватом |
| Gate/Expander (сетка ручек + график передачи) | ✅ подтверждено реальным захватом |
| Эквалайзер (4 полосы: freq/gain/width + вкл/выкл) | ⚠️ подтверждено только описанием в списке команд |
| Посылы канала на 16 aux-шин | ⚠️ не подтверждено реальным захватом |
| Мастер, Aux Returns (8), сами aux-шины (16, с цветом) | ⚠️ не подтверждено реальным захватом |
| VCA-группы (8) | ✅ полностью подтверждено реальным захватом |
| Банки каналов (по 8), альбомная/портретная ориентация | ✅ |

### Мониторный режим

- Список всех 16 aux-шин (с живыми именами) при подключении
- Посылы всех каналов в выбранную свою шину — фейдер на всю высоту канала
- Громкость и mute самой шины
- Каналы постранично, по 8 за раз
- Работает в портретной и альбомной ориентации

## Технические особенности протокола (важно при доработке)

- Пульт **не отвечает** на прямой `--get` по человекочитаемому пути. Живые
  обновления идут только через подписку `/batchsubscribe` с клиентским
  хендлом + периодический `/renew` (~3 сек) для продления — без него пульт
  отключает подписку через какое-то время.
- Хендлы подписки должны быть **уникальными на сессию** (иначе пульт может
  путать данные со старыми подписками прошлых запусков).
- Push-значения (через подписку) кодируются в **little-endian**, а команды
  `--set`/`--get` — в **big-endian** (стандартный OSC).
- Цвет канала — не обычный ARGB: байты идут в порядке **R, G, B, A**.
- Mute у входных каналов, мастера, aux returns и aux-шин — это **toggle**
  (переключение на любой полученный пакет), а не установка в явное
  значение. VCA использует ту же логику.
- Пульт различает подключённых клиентов **только по IP-адресу**, не по
  порту — при двух активных сессиях с одного IP он путается, куда слать
  ответы. Поэтому у приложения один порт (10001) на оба режима.
- VCA-группы адресуются **иначе**, чем можно было бы предположить по
  некоторым сторонним спискам команд: не `enMCAFaderLevel1..8` (номер в
  имени параметра), а обычный multiPath-паттерн (`enVCAFaderLevel` с
  индексом-аргументом), как и всё остальное.
- Реализована защита от разрыва соединения при повороте экрана
  (`ConnectionHolder` — синглтон вне жизненного цикла `Activity`).

Подробный уровень уверенности по каждой конкретной команде — прямо в
комментариях `Pro2Commands.kt`.

## Сборка

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите на устройстве в одной сети с пультом (`Run` → выбрать
   устройство).

Требования: Android Studio, minSdk 24, Kotlin.

## Пульт

Тестировалось на **Midas Pro2** (56 входных каналов, 8 aux returns, 16
aux-шин, 3 мастер-канала, 8 VCA-групп, до 6 mute-групп). Другие консоли
Pro-серии (Pro1/Pro3/Pro X) могут частично поддерживаться, но не
проверялись.

## Известные ограничения

- **Числовые значения параметров показываются как сырое число 0.00–1.00**,
  а не в реальных единицах (дБ, мс и т.п.) — у нас нет подтверждённой
  формулы перевода для большинства параметров. Для части параметров
  компрессора (threshold/attack/release) в списке команд есть подсказки
  вида "0=-50дБ, 0.35=-25дБ, 0.65=0дБ, 1=25дБ", но не для всех и не всегда
  линейно. Работа над точным отображением в очереди.
- График передачи компрессора/gate — иллюстративный, не откалиброван под
  реальные дБ пульта (см. комментарий в `TransferCurveView.kt`).

## В планах

- Точные единицы измерения (дБ/мс) вместо сырых значений 0.00–1.00
- Перевод интерфейса на английский
- Mute-группы
- 31-полосный графический EQ, Pan-фильтры (high-pass/low-pass)
- Matrix-выходы (`enVirtualMainOuts`)
